# Tawuniya VR

تجارب VR للتعاونية وكيرهب (Three.js / WebXR). المشاهد: `reception/` استقبال المستشفى، `accident/` موقع الحادث، `showroom/` معرض السيارات، `home/` بيت أبو محمد، `carehub/` عيادة كيرهب، `journey/` رحلة كيرهب من البيت للعيادة (فيها وضع تلقائي `?auto=1`).

## التشغيل محليًا (بدون إنترنت)
الصفحات لازم تتفتح من سيرفر مش بدبل كليك على `index.html`:

- على الماك: دبل كليك على `serve.command` (أول مرة: كليك يمين → Open)، وهيفتح المتصفح على http://localhost:8090/
- أو من الطرفية: `python3 -m http.server 8090` جوه الفولدر.

المكتبات والخط موجودين جوه `vendor/` فمافيش حاجة بتتحمّل من الإنترنت.

## VR
افتح نفس الرابط من متصفح Meta Quest (لازم https على الإنترنت، أو GitHub Pages). الأصوات في `*/media/` متولّدة بـ ElevenLabs v4 وباللهجة السعودية البيضاء.
